# Переменная `{{ this }}` в dbt

`{{ this }}` — специальная переменная dbt, которая возвращает полное имя текущей модели в хранилище данных.

Она позволяет SQL-модели обращаться к собственной целевой таблице или представлению.

## 1. Как работает `{{ this }}`

Представим, что у нас есть модель `orders_inc.sql`:

```sql
{{
    config(
        materialized='incremental',
        unique_key='order_id'
    )
}}

select
    order_id,
    client_id,
    amount

from {{ source('raw', 'orders') }}

{% if is_incremental() %}

where order_id > (
    select max(order_id)
    from {{ this }}
)

{% endif %}
```

Допустим:
- Название модели: `orders_inc`.
- Схема: `dev_evgen`.
- База данных: `shop`.

Тогда:

```sql
from {{ this }}
```

dbt преобразует примерно в:

```sql
from shop.dev_evgen.orders_inc
```

То есть модель обращается к собственной целевой таблице.

Точное полное имя зависит от используемого адаптера и настроек подключения.

## 2. Зачем используется `{{ this }}`?

Чаще всего `{{ this }}` применяется в incremental-моделях, чтобы сравнивать поступающие данные с уже загруженными.

Например, нам необходимо загружать только новые заказы.

### Первый запуск

В источнике `raw.orders` находится 10 записей.

Целевая таблица `orders_inc` ещё не существует.

При первом запуске:

```sql
{% if is_incremental() %}
    where order_id > (
        select max(order_id)
        from {{ this }}
    )
{% endif %}
```

Условие `is_incremental()` возвращает `false`, поэтому фильтр не применяется.

dbt загружает все 10 записей и создаёт целевую таблицу.

### Второй запуск

В источник добавили ещё 5 записей.

Теперь:
- `raw.orders` содержит 15 записей.
- `orders_inc` содержит 10 записей.

При повторном запуске `is_incremental()` возвращает `true`.

dbt выполняет условие:

```sql
where order_id > (
    select max(order_id)
    from {{ this }}
)
```

Поскольку `{{ this }}` указывает на `orders_inc`, запрос фактически выглядит так:

```sql
where order_id > (
    select max(order_id)
    from shop.dev_evgen.orders_inc
)
```

Максимальный `order_id` в целевой таблице равен 10.

Следовательно, dbt выберет только записи с `order_id > 10`.

В результате в таблице окажется 15 записей.

## 3. Отличие `{{ this }}` от `source()` и `ref()`

| Конструкция | Назначение |
|---|---|
| `{{ source('raw', 'orders') }}` | Обращение к исходной таблице, описанной в `sources.yml` |
| `{{ ref('stg_orders') }}` | Обращение к другой модели dbt |
| `{{ this }}` | Обращение к текущей модели в хранилище |

## 4. Важные особенности

- `{{ this }}` не создаёт таблицу и не загружает данные.
- Переменная подставляет имя текущей модели в SQL.
- Часто используется совместно с `is_incremental()`.
- Позволяет получать информацию о данных, которые уже находятся в целевой таблице.
- Может применяться не только в incremental-моделях, но и в других SQL-моделях и макросах, где нужен адрес текущего объекта.

## Главное

`{{ this }}` — это ссылка на текущую модель dbt в хранилище данных.

В incremental-моделях она особенно полезна: позволяет сравнивать новые данные с уже загруженными и определять, какие записи необходимо обработать.
